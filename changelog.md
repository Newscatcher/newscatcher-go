## v2.0.0 - 2026-03-19
* The aggregation functionality has been removed from the SDK. All aggregation-related types including `AggregationGetRequest`, `AggregationPostRequest`, `AggregationCountResponseDto`, and related enums are no longer available. Applications using these types will need to be updated to remove aggregation functionality.
* The `aggregation` package has been removed entirely, including the `Client` type and its `Get()` and `Post()` methods for retrieving article counts. All latest headlines types including `LatestHeadlinesGetRequest`, `LatestHeadlinesPostRequest`, `LatestHeadlinesGetResponse`, and `LatestHeadlinesPostResponse` have also been removed. Applications using these APIs will need to migrate to alternative endpoints or wait for replacement functionality.
* The search by link/ID functionality has been removed from the SDK. The `searchlink.Client` with its `SearchUrlGet()` and `SearchUrlPost()` methods, along with related types `SearchUrlPostRequest`, `SearchUrlGetRequest`, `Ids`, and `Links`, are no longer available. Applications using these features will need to migrate to alternative search methods.
* The search similar endpoint functionality has been removed from the SDK. All related types including SearchSimilarGetRequest, SearchSimilarPostRequest, SearchSimilarResponseDto, FailedSearchSimilarResponseDto, SimilarArticleEntity, and SimilarDocument are no longer available. Code using these types will need to be updated to use alternative search endpoints.
* The `searchsimilar` package has been removed entirely. All functionality for finding similar articles is no longer available. Any imports of `github.com/Newscatcher/newscatcher-go/searchsimilar` or usage of `searchsimilar.Client` will need to be removed from your code.
* Breaking change: The `AuthorsGetRequest` and `AuthorsPostRequest` types have been renamed to `GetAuthorsRequest` and `PostAuthorsRequest` respectively. Update your code to use the new type names. The SDK now includes explicit field tracking with new setter methods for all request parameters.
* The `NewClient` constructor now requires a `*core.RequestOptions` parameter instead of accepting variadic options. Replace `NewClient(option1, option2)` with `NewClient(core.NewRequestOptions(option1, option2))`. The client also now includes a `WithRawResponse` field that provides access to raw HTTP responses.
* Breaking news request types renamed for consistency: `BreakingNewsGetRequest` is now `GetBreakingNewsRequest` and `BreakingNewsPostRequest` is now `PostBreakingNewsRequest`. The `ContentSentientMax` field in POST requests has been corrected to `ContentSentimentMax`. All request types now include SetX methods for explicit field control.
* Major SDK restructure introduces versioned packages and new client architecture. All import paths now use the v505/ namespace. Client constructors now require a *core.RequestOptions parameter instead of variadic options. Method names simplified: BreakingNewsGet/Post renamed to Get/Post. New WithRawResponse field provides access to raw HTTP response data, and MaxBufSize option added for streaming configuration. Migration required for all existing code.
* Breaking change: Search request and response types have been renamed to follow Go naming conventions. `SearchGetRequest` is now `GetSearchRequest`, `SearchPostRequest` is now `PostSearchRequest`, `SearchGetResponse` is now `GetSearchResponse`, and `SearchPostResponse` is now `PostSearchResponse`. Update your code to use the new type names.
* The `search.NewClient()` constructor signature has changed from accepting variadic options to requiring a single `*core.RequestOptions` parameter. Update your client initialization from `search.NewClient(option1, option2)` to `search.NewClient(core.NewRequestOptions(option1, option2))`. Additionally, request types have been renamed: `SourcesGetRequest` is now `GetSourcesRequest` and `SourcesPostRequest` is now `PostSourcesRequest`.
* Major SDK refactor with breaking changes to client constructors and package structure. Client constructors now require `*core.RequestOptions` instead of variadic options, and package imports have moved to versioned paths. Request types have been renamed (e.g., `SourcesGetRequest` is now `GetSourcesRequest`). Clients now include a `WithRawResponse` field for direct access to HTTP responses.
* New link analysis capabilities with AllLinksDataItem providing detailed information about links mentioned in articles, including domain, URL, and anchor text. The AllLinksText parameter enables filtering by link anchor text content. Enhanced field serialization control with new SetX() methods on all struct types.
* New aggregation count API endpoints are now available, enabling time-based article counting and analytics. The SDK supports aggregating news data by day, hour, or month intervals with over 45 filtering parameters including sources, languages, countries, sentiment analysis, and entity recognition.
* The SDK now supports accessing raw HTTP responses alongside parsed response bodies. Use the `WithRawResponse` property on any client to get both status codes and headers in addition to the response body.
* New latest headlines API endpoints available with extensive filtering options including language, country, sources, sentiment analysis, and content taxonomy support.
* The SDK now supports search-by-link functionality, allowing you to search for articles using their ID or URL through the new `SearchByLink` client. Raw HTTP client modules are also available for all API endpoints, providing lower-level access to HTTP responses.
