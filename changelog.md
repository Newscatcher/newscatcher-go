## v2.0.0 - 2026-03-16
* The latest headlines endpoint and search by link functionality have been removed from the SDK. All related types including `LatestHeadlinesGetRequest`, `LatestHeadlinesPostRequest`, `SearchUrlGetRequest`, `SearchUrlPostRequest`, and their response types are no longer available. Applications using these features will need to migrate to alternative search endpoints.
* The `searchlink` package has been removed. Applications using `searchlink.Client`, `SearchUrlGet()`, or `SearchUrlPost()` methods must migrate to alternative search methods or use the REST API directly.
* The SearchSimilar API functionality has been completely removed from the SDK. All SearchSimilar-related types, methods, and endpoints are no longer available. Applications using SearchSimilar functionality must migrate to alternative search methods or use a different SDK version.
* The `searchsimilar` package has been removed entirely. All functionality for searching similar articles is no longer available. Remove any imports of `github.com/Newscatcher/newscatcher-go/searchsimilar` and calls to `searchsimilar.Client` methods from your code.
* The aggregation API types have been restructured with clearer naming. `AggregationGetRequest` and `AggregationPostRequest` are now `AggregationCountGetRequest` and `AggregationCountPostRequest`. All aggregation types now include setter methods for better field control during serialization.
* Breaking changes to the aggregation client: the `Get` method has been renamed to `CountGet` and the `Post` method has been renamed to `CountPost`. Update your method calls accordingly.
* The authors endpoint request types now include improved field validation and type safety. New named types replace primitive types for better API consistency, and SetX() methods are available for all request parameters to ensure proper field validation. The AllLinksText parameter is now available for searching link text content.
* The authors client now provides access to raw HTTP responses through the new `WithRawResponse` field, enabling advanced use cases like custom error handling and response header access.
* The SDK now uses explicit field tracking to prevent zero-value fields from being omitted during serialization. Field types have been updated to use dedicated type aliases, and comprehensive setter methods are now available for all struct fields. The Content field in BreakingNewsArticleEntity is now optional and returns a pointer to support null values.
* Breaking changes to client initialization: `NewClient()` now requires a `*core.RequestOptions` parameter instead of variadic options. Method names have been updated for consistency: `latestheadlines.Client.Get()` is now `LatestHeadlinesGet()` and `latestheadlines.Client.Post()` is now `LatestHeadlinesPost()`. All clients now include a `WithRawResponse` field that provides access to raw HTTP responses including status codes and headers.
* The SDK now includes improved type safety with explicit field setters and a new raw response access pattern. Added support for robots compliance data in source information.
* The SDK now supports raw HTTP response access through the new `WithRawResponse` field on all clients. Added new `SetXXX` methods on response types for explicit field serialization control. Import paths have been updated to use the v505 namespace for better version management.
* The SDK now supports advanced link analysis with the new `AllLinksDataItem` type providing detailed information about links found in articles, including domain URLs, complete URLs, and anchor text. Added `AllLinksText` parameter for searching articles by link anchor text. Enhanced field serialization with new `SetXXX` methods for explicit field control and improved nil-safety across all getter methods.
* Breaking change: All import paths have been updated to use the versioned module path `github.com/Newscatcher/newscatcher-go/v505`. Update your imports from `github.com/Newscatcher/newscatcher-go/...` to `github.com/Newscatcher/newscatcher-go/v505/...`. Additionally, the client field `Latestheadlines` has been renamed to `LatestHeadlines`, `SearchLink` to `SearchByLink`, and `Searchsimilar` has been removed.
* New latest headlines API endpoint support with comprehensive filtering options including language, country, sources, sentiment analysis, and content categorization.
* New search-by-link functionality allows searching for articles using either article IDs or direct links through the `searchbylink` package. The SDK also adds a new `Bytes()` utility function for creating []byte pointers.
